## 1. Отключить BitLocker / Device encryption

На многих ноутбуках с Windows 11 Home включено **шифрование устройства** (Device encryption). Это упрощённый BitLocker.

Omarchy (и любой Linux) **не сможет нормально работать** с зашифрованным Windows-диском, а при изменениях разделов BitLocker часто требует recovery key.

### Способ А — через Параметры (самый простой)

1. Откройте **Параметры** (Win + I).
2. Перейдите в **Конфиденциальность и защита** → **Шифрование устройства**  
   (Privacy & security → Device encryption).
3. Если видите переключатель **Шифрование устройства** — выключите его.
4. Подтвердите действие.
5. Дождитесь полного завершения расшифровки (может занять от нескольких минут до часа в зависимости от заполненности диска).

> Если пункта «Шифрование устройства» нет — значит оно уже выключено или у вас Windows 11 Pro с классическим BitLocker.

### Способ Б — классический BitLocker (Windows 11 Pro)

1. Нажмите Win + R → введите `control` → Enter.
2. Перейдите в **Система и безопасность** → **Шифрование диска BitLocker**.
3. Напротив диска C: нажмите **Отключить BitLocker**.
4. Дождитесь завершения расшифровки.

### Способ В — через PowerShell (если меню не находится)

Откройте PowerShell **от имени администратора** и выполните:

```powershell
# Проверить статус
Get-BitLockerVolume

# Отключить шифрование на C:
Disable-BitLocker -MountPoint "C:"
```

После команды статус будет «Decryption in progress». Не выключайте ноутбук до завершения.

### Как понять, что всё отключено

- В Параметрах переключатель серый/выключен.
- В `Get-BitLockerVolume` у тома C: стоит `Protection Status : Off` и `Volume Status : FullyDecrypted`.

## 2. Отключить Fast Startup (Быстрый запуск)

Fast Startup — это гибридная гибернация. Из-за неё Linux может видеть диск Windows как «грязный» (dirty) и отказываться монтировать NTFS-разделы в режиме записи.

### Как отключить

1. Win + R → введите `powercfg.cpl` → Enter.
2. Слева нажмите **Действия кнопок питания**.
3. Сверху нажмите **Изменение параметров, которые сейчас недоступны**.
4. Снимите галочку **Включить быстрый запуск (рекомендуется)**.
5. Сохраните изменения.

### Альтернатива через командную строку (от администратора)

```cmd
powercfg /h off
```

Эта команда полностью отключает гибернацию и Fast Startup.

## 3. Дополнительные рекомендации

### Отключить гибернацию полностью (уже сделано командой выше)

```cmd
powercfg /h off
```

### Проверить, что Windows видит оба диска

1. Win + X → **Управление дисками**.
2. Убедитесь, что видны:
   - Диск 512 ГБ (Windows)
   - Диск 1 ТБ (пока может быть «Не распределён» или со старыми разделами)

### Создать точку восстановления (на всякий случай)

Параметры → Система → О системе → Защита системы → Создать.

## Краткий чеклист перед разметкой 1 ТБ диска

- [ ] BitLocker / Device encryption **полностью выключен** и диск расшифрован
- [ ] Fast Startup **выключен**
- [ ] `powercfg /h off` выполнен
- [ ] Windows нормально загружается
- [ ] Есть доступ в интернет (на всякий случай)

После этого можно загружаться с GParted Live и размечать диск 1 ТБ.
