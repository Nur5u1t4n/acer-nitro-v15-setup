# Разметка дисков — какой инструмент использовать

## Проблема с EFI-разделом

Windows Disk Management и многие Windows-программы **плохо** умеют:
- Удалять существующий EFI-раздел
- Создавать новый EFI нужного размера (1 ГБ)
- Правильно ставить флаг ESP

Поэтому для диска 1 ТБ (под Omarchy + DATA) лучше использовать **Linux-инструменты**.

## Рекомендуемый инструмент: GParted Live

**GParted** — лучший выбор для нашей задачи.

### Почему GParted

- Полностью управляет GPT и EFI-разделами
- Может удалить старый EFI и создать новый на 1 ГБ
- Умеет ставить флаг `esp` / `boot`
- Работает с NTFS, FAT32, Btrfs и т.д.
- Есть Live USB — можно загрузиться и спокойно разметить диск, не трогая работающую систему

### Как подготовить GParted Live

1. Скачать ISO: https://gparted.org/download.php
2. Записать на флешку через:
   - **Rufus** (Windows) — схема GPT, целевая система UEFI
   - **balenaEtcher**
   - **Ventoy** (удобно, если уже используете)
3. В BIOS отключить Secure Boot (см. `bios-settings.md`)
4. Загрузиться с флешки (F12 → выбрать UEFI: GParted / USB)

### Порядок разметки диска 1 ТБ в GParted

1. Выбрать правильный диск (смотреть размер 931 ГБ / 1 ТБ).
2. Если диск новый / нужно с нуля:
   - Device → Create Partition Table → **gpt**
3. Создать разделы по порядку:

| № | Размер | Файловая система | Флаги | Метка | Назначение |
|---|--------|------------------|-------|-------|------------|
| 1 | **1024 МБ** | fat32 | `esp` (boot) | EFI | EFI System Partition |
| 2 | **350 ГБ** | (оставить unformatted или btrfs) | — | omarchy | Под систему Omarchy |
| 3 | **остальное** | ntfs | — | DATA | Общий раздел данных |

4. Применить все операции (зелёная галочка).
5. Для раздела DATA можно сразу поставить метку `DATA`.

> Раздел под Omarchy лучше оставить **неформатированным** или отформатировать в btrfs — установщик Omarchy всё равно будет работать с ним (особенно если используете manual / free-space install).

## Альтернативы

| Инструмент | Плюсы | Минусы |
|------------|-------|--------|
| **GParted Live** | Лучший контроль над EFI, GUI | Нужна отдельная флешка |
| **Omarchy / Arch live** + `cfdisk` / `parted` | Не нужна лишняя флешка | Сложнее для новичков |
| Windows Disk Management | Уже есть | Не может нормально создать/удалить EFI 1 ГБ |
| diskpart (Windows) | Мощный | Тоже ограничен с EFI, легко ошибиться |
| MiniTool / EaseUS и т.п. | GUI в Windows | Часто платные, иногда глючат с ESP |

**Вывод:** для создания чистого 1 ГБ EFI на диске под Linux используем **GParted Live**.

## Диск 512 ГБ (Windows)

Его лучше **не трогать** вручную.

Просто при установке Windows 11 выбрать этот диск и дать установщику создать разделы самому (EFI + MSR + Windows + Recovery).

## Важные предупреждения

- Перед любой разметкой сделайте бэкап важных данных.
- В GParted **очень внимательно** выбирайте диск (смотрите размер и модель).
- После создания разделов на 1 ТБ диск Windows их увидит, но системным он не станет, пока не установите Omarchy.
