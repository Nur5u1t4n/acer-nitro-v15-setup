# План разметки дисков

**Дата принятия решения:** 2026-10-01

## Диски в ноутбуке

| Диск | Объём | Роль |
|------|-------|------|
| SSD 1 | 1 ТБ | **Omarchy** (основная система) |
| SSD 2 | 512 ГБ | **Windows 11** |

## Рекомендуемая схема

### Диск 1 ТБ → Omarchy (full-disk)

Omarchy при full-disk install сам создаст:

- EFI-раздел (~1 ГБ, FAT32)
- LUKS-контейнер на оставшемся пространстве
- Внутри LUKS — Btrfs с субволюмами (`@`, `@home`, `@snapshots` и т.д.)

Это самый простой и рекомендуемый путь для Omarchy.

### Диск 512 ГБ → Windows 11

При установке Windows 11 (чистая) установщик сам создаст:

- EFI System Partition (100–500 МБ)
- MSR (Microsoft Reserved)
- Основной раздел Windows (NTFS)
- Recovery Partition

Мы можем дополнительно управлять размерами через `autounattend.xml`, но для начала достаточно стандартной разметки Windows.

## Порядок действий

1. В BIOS выбрать, какой диск будет первым (лучше оставить 1 ТБ как основной для Limine).
2. Установить Windows 11 **только** на диск 512 ГБ.
3. Убедиться, что Windows загружается.
4. Отключить BitLocker и Fast Startup.
5. Установить Omarchy на диск 1 ТБ (full disk).
6. После установки Omarchy:
   ```bash
   sudo limine-scan
   ```
   Добавить Windows Boot Manager в меню Limine.

## Альтернативы (не рекомендуем сейчас)

- Оба ОС на одном диске (1 ТБ) + 512 ГБ как data — возможна, но сложнее с шифрованием и обновлениями.
- Windows на 1 ТБ, Linux на 512 ГБ — противоречит тому, что Linux основная.

## Примечания

- При dual-boot на разных дисках Secure Boot должен быть выключен.
- Limine станет основным загрузчиком.
- Windows можно будет запускать из меню Limine или через Boot Menu BIOS (F12/F7 и т.п.).
