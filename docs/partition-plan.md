# План разметки дисков (финальный вариант)

**Дата:** 2026-10-01  
**Требование пользователя:** общий раздел с данными, доступный из Windows и Linux, который не удаляется при переустановке систем.

## Диски

| Диск | Объём | Роль |
|------|-------|------|
| SSD 1 | **1 ТБ** | Omarchy + **общий DATA** |
| SSD 2 | **512 ГБ** | Только Windows 11 |

## Подробная разметка

### Диск 1 ТБ

```
┌─────────────────────────────────────────────────────┐
│ EFI          1 ГБ     FAT32     (Limine)            │
├─────────────────────────────────────────────────────┤
│ Omarchy     250–350 ГБ  Btrfs+LUKS   (система)      │
├─────────────────────────────────────────────────────┤
│ DATA        ~650–750 ГБ   NTFS     (общие данные)   │
└─────────────────────────────────────────────────────┘
```

**Рекомендуемые размеры:**
- Omarchy: **300 ГБ** (комфортно для системы + программ + snapshots)
- DATA: всё остальное (~700 ГБ)

Можно сделать Omarchy 250 ГБ, если хочется максимум места под данные.

### Диск 512 ГБ

Стандартная разметка Windows 11 (создаётся установщиком):

- EFI (~100–500 МБ)
- MSR
- Windows (C:) — почти весь диск
- Recovery

## Файловая система общего раздела

**NTFS** — лучший выбор:

- Windows работает с ним нативно
- Linux отлично читает/пишет через драйвер `ntfs3` (в ядре) или `ntfs-3g`
- Поддерживает большие файлы
- Права доступа можно настроить

Альтернатива: exFAT (проще, но хуже с правами и метаданными).

## Как будет выглядеть доступ

**В Windows:**
- Диск `D:` (или другая буква) с меткой `DATA`

**В Omarchy (Linux):**
- Монтируется, например, в `/mnt/data` или `/data`
- Можно сделать символические ссылки:
  - `~/Documents` → `/data/Documents`
  - `~/Downloads` → `/data/Downloads`
  - `~/Pictures` → `/data/Pictures`
  - и т.д.

## Важные правила

1. При переустановке **Windows** — трогаем только диск 512 ГБ.
2. При переустановке **Omarchy** — трогаем только раздел Omarchy на 1 ТБ (EFI можно оставить).
3. Раздел **DATA** никогда не форматируем при переустановке систем.
4. Перед любой переустановкой лучше сделать бэкап важных данных (на всякий случай).

## Следующие шаги

- Решить точный размер раздела Omarchy (250 / 300 / 350 ГБ?)
- Подготовить инструкцию по ручной разметке диска 1 ТБ
- Настроить автомонтирование DATA в Omarchy
