# Acer Nitro V15-41 Dual-Boot Setup

**Цель:** Чистая установка **Windows 11** + **Omarchy** (Arch Linux + Hyprland) на ноутбук Acer Nitro V 15 (ANV15-41).

Linux (Omarchy) — **основная** система.  
Windows 11 — для игр и программ, которым нужен Windows.

**Обязательное требование:** общий раздел с данными, доступный из обеих систем, который **не удаляется** при переустановке ОС.

---

## Принятые решения

| Решение | Выбор |
|---------|-------|
| Целевой ноутбук | Acer Nitro V15-41 (ANV15-41) |
| Основная ОС | Omarchy (Arch + Hyprland) |
| Вторая ОС | Windows 11 (чистая, debloat) |
| Dual-boot | Да |
| Диски | **2 SSD**: 1 ТБ + 512 ГБ |
| Общий раздел данных | **Да** (NTFS), доступен из Windows и Linux |
| Bootloader | Limine (от Omarchy) |

### Железо
- Диски: 1 × 1 ТБ + 1 × 512 ГБ SSD
- Графика: Hybrid AMD Radeon + NVIDIA RTX

---

## Разметка дисков (новая схема)

### Диск 1 — 1 ТБ

| Раздел | Размер | ФС | Назначение |
|--------|--------|----|------------|
| EFI | 1 ГБ | FAT32 | ESP (Limine) |
| Omarchy | 250–350 ГБ | Btrfs + LUKS | Корневая система Linux |
| **DATA** | **остальное (~650–750 ГБ)** | **NTFS** | **Общие данные** (фото, документы, игры, загрузки и т.д.) |

### Диск 2 — 512 ГБ

| Раздел | Размер | ФС | Назначение |
|--------|--------|----|------------|
| EFI | ~100–500 МБ | FAT32 | Windows EFI |
| MSR | ~16 МБ | — | Microsoft Reserved |
| Windows (C:) | почти всё | NTFS | Windows 11 + установленные программы/игры |
| Recovery | ~1 ГБ | NTFS | Восстановление |

### Почему так

- Общий раздел **DATA** живёт отдельно от системных разделов → при переустановке Windows или Omarchy он остаётся нетронутым.
- NTFS читается и пишется и из Windows, и из Linux (драйвер `ntfs3` / `ntfs-3g`).
- Linux получает достаточно места (250–350 ГБ) + огромный общий раздел.
- Windows получает целый 512 ГБ диск.

---

## Порядок установки (обновлённый)

1. **BIOS**: Secure Boot OFF, TPM OFF, UEFI.
2. Установить **Windows 11** на диск **512 ГБ**.
3. В Windows отключить BitLocker и Fast Startup.
4. Разметить диск **1 ТБ**:
   - Создать EFI (1 ГБ)
   - Создать раздел под Omarchy (250–350 ГБ)
   - Оставшееся пространство → NTFS-раздел с меткой `DATA`
5. Установить **Omarchy** на подготовленный раздел (не full-disk, а на конкретный раздел).
6. После установки Omarchy:
   - Добавить Windows в Limine (`sudo limine-scan`)
   - Настроить автоматическое монтирование раздела DATA в Linux.
